卷尼玛

我在第一次接触 Java 时便被它深深吸引，对我来说，它太熟悉了

Java 和 C++ 很像，不是写法，是整个语言的感觉，无论是循环的关键字还是语法结构，以及结尾上的小字符，真的，非常非常像，有时候写 Java 代码，我甚至都会愣神

而 Java 独有的一些机制，用法，以及设计，常常让我很兴奋，很惊喜。我不可否认，我爱上了这门语言，它让我重拾了探索的欲望，恢复了学习的热情

但我很容易陷入一个怪圈，因为它们太像，我常常在写 Java 代码时便不由自主的把 C++ 的语法强行带入，于是反复发问，为什么它会没有指针，为什么它不可以多继承，为什么它不支持运算符重载

……

可是，它为什么需要有这些？凭什么就需要有这些？就因为 C++ 第一个对你说“你好世界”吗？

后来，她去了西安，成了一名 Java 开发工程师，不仅是合格，应该称得上优秀；而我还在秦皇岛，还是一名 C++ 老师，谈不上优秀，应该算得上合格

......

再后来，她去了松山湖，做着安全相关的工作。东莞的烧鹅很好吃，小姐也年轻 —— 当然，那是以前

这些年技术更新得飞快，外面不停嚷嚷着 AI、超级个体，好像叫得越凶，股价就涨得越狠。不过前端兄弟的命确实被革掉了，后端也快了。她的工作与智能体有关，在后 GPT 时代，C++ 早就被遗忘在一座靠海的小城 —— 即使她喜欢海

......

我厌倦了 Java 的继承，一层一层往上攀的父类，盘根错节的族系，总让我想起世袭的皇帝。我放弃了 Java，放弃了海，也放弃了她。那是一场不亚于土地改革的解放

我正在西二旗呼吸新鲜空气，像一个刚分到田的农民在开垦属于自己的土地。她有 Java 的模样，也有 C++ 的影子，她有云原生时代的所有气质

北京没有海，风很燥。我正在和她磨合，希望我们相处愉快

......

可日子久了，无止境的组合也变得发苦、发闷，泛型来得那样迟，错误处理翻来覆去只有一句 if err != nil —— 敲着敲着，我又想起当年那些问题。只是这一次，我没有愣神 —— 它不必有指针，不必有多继承，不必有运算符重载；它不必像 C++，也不必像 Java —— 它不必长成我记忆里的样子

企鹅岛四周都是海，风很润。原来海并没有被我放弃，它只是换了一种方式重新把我围住，而我又重新在自己选的岸上开垦，周而复始
