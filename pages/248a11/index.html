# 动作框架

老陕大师课

  • 乒乒球是两个人在用身体角力，用身体在抗，而并非手臂
  • 发力的基础在于腰腹和手的整体性，发力的关键在于手腕的爆发力
  • 只有足够放松，手腕才有足够的发力空间，越放松越爆

正手框架

  1. 重心要低：头仅比网高一点，一是利于发动，二是利于制造弧线，身子低击球全是半高
  2. 发力集中在身体和手腕：不需要关注大臂小臂，仅仅关注手腕就行，放松后凌空鞭打，在篮球大小范围中集中发力，靠撞击透板，靠吃球深度加摩擦
  3. 脚底踩住控制节奏：连续性很大程度上取决于步伐，击球瞬间（0.3s 不到）一定要把重心踩死在右脚，并且进行大幅度的蹬转；这是找准节奏的关键，可以适当的喊口号或调整呼吸去找踩重心 → 发力的节奏
  4. 松紧控制：手腕一定要放松，放松有助于发力，但身子、腰、腿不能散，必须得集中

不同的身体部位负责不同的工作

  1. 发力在于手部（始终在靠近身子的篮球大小范围发力），这意味着，在发力范围外，引拍应当放松，收拍应当制动停顿
  2. 节奏调整和重心在于腰腿，腰腿是一直绷住的，集中的，不能散，唯一能放松的是手部的非篮球区域

手臂控制的关键：越靠近身子，越容易控制，能不能透板仅仅在于靠近身子的篮球大小范围的瞬间发力

  • 0.1s 的事，不要有附加的手臂动作，这只会让球不稳定
  • 旋转也是在那 0.1s 的撞击中，由手腕加上的，而并非手臂的工作

反手

  • 首先一定是要找点，肚子是母球，只有当母球和乒乒球处于一条线上时，你的击打才是简单的，相当于直塞
  • 其次引拍一定要压腕，压腕是为了给转腕留空间，转腕不等于甩腕，整个反手框架中，手腕不会前后移动，而只有以手腕为支点的旋转，这样和整个身体维持一个稳定的整体同时保证手腕的灵活度

击球要有整体性：身体带动手移动，二者是一个整体，这样动作既稳定，力的传导也没有损失

  • 甩手去鞭打远小于整体框架的发力加上转腕的发力
  • 强调手不发力，靠身体吃住球，挂起来，通过瞬间制动手腕来鞭打

打乒乓球不需要发力，想要发力，就得放松手腕再制动

# 发抢技战术

通过发球为第三板制造主动

顺旋转到正手短 + 反手长 + 中间长：为什么马龙、马琳喜欢发左侧旋球 | bilibili (opens new window)

  • 反手长降低回球质量，衔接反手撕 / 侧身冲
  • 若对手回摆就立即劈反手长，回到反手长的逻辑，准备反手撕 / 侧身冲

逆旋转到正手短限制拧拉，逼迫对手正手劈长，此时衔接反手冲 / 正手冲；逆旋转反手长少发，以牵制为主

特殊胶皮处理：发球无脑冲颗粒长，上下旋换着来
