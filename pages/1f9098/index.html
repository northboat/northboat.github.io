ESP32 固件开发

# ESP32 基础

固件开发，本质上就是在电脑上编代码，然后把交叉编译的二进制程序烧录到硬件上

  1. 编码：VSCode + Espressif IDF 插件 Vibe 即可
  2. 编译：ESP-IDF 提供 arm64 交叉编译工具链
  3. 烧录：ESP-IDF 提供现有的烧录工具 esptool.py（python 包）

很多教程里会使用 Arduino IDE 去开发 ESP32，其实就是在 GUI 里集成了 IDF Cli。IDF 指 IoT Development Framework 物联网开发框架 —— 一个以 idf.py 为入口的 Python 包

备份出厂系统（16MB）

  • 完整的存储容量由固件信息 Detected flash size: 32MB 得知有 32MB
  • 为什么只备份 16MB？分区表里最后的一行 storage, data, spiffs, 0x800000, 8M，初始地址 8MB + 偏移量 8MB 的到出厂固件布局的使用上限（这套固件只设计了前 16MB）
esptool.py --chip esp32s3 -p /dev/cu.usbmodem1201 flash_id

esptool.py --chip esp32s3 -p /dev/cu.usbmodem1201 \
  read_flash 0 0x1000000 ~/Workspace/esp/factory_backup_16m.bin

# FreeRTOS

ESP32-S3 的内核（几 KB），支持可抢占的任务和线程，单地址空间（读 cache 访问 flash），任务各有栈，通过主程序 void app_main(void) 载入

# hello-world

新建工程

idf.py create-project hello
cd hello
idf.py set-target esp32s3
1
2
3

编译

idf.py build
1
  • 产物在 build/ 下，bootloader.bin、partition-table.bin、hello.bin 三个文件分别对应烧录地址 0x0、0x8000、0x10000

烧录

ls /dev/cu.*
idf.py -p /dev/cu.usbmodem1101 flash
1
2

看日志

idf.py -p /dev/cu.usbmodem1101 monitor
1

Ctrl+] 退出，原生 USB 下 Ctrl+T Ctrl+R 软复位。和烧录合成一条也是一样的

idf.py -p /dev/cu.usbmodem1101 flash monitor
1

如果只烧录现成的 bin，不装 IDF 也能烧，单独装 esptool 即可

brew install esptool
esptool.py --chip esp32s3 -p /dev/cu.usbmodem1101 -b 460800 \
  write_flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 hello.bin
1
2
3

也可以先合并成单个文件再一把烧

esptool.py --chip esp32s3 merge_bin -o merged.bin \
  --flash_mode dio --flash_size 8MB \
  0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 hello.bin
1
2
3
